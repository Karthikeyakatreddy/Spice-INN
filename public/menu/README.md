# Spice Inn — Original Menu Images

Place your restaurant menu image files here as:

- `menu-1.jpg`
- `menu-2.jpg`
- ...
- `menu-8.jpg`

They'll be loaded by the **Original Menu** gallery on the `/menu` page,
shown with `object-contain` so they are never cropped, and openable
full-screen with prev/next/close controls.
